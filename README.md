# Luxury Cafe Concierge — Ajay Intercontinental 🍽️

A premium, royal-themed digital dining assistant designed to provide a high-end concierge experience for Ajay Intercontinental. This application features a sophisticated chatbot interface, real-time cart management, and a luxury design aesthetic.

## ✨ Key Features
- **Premium UI/UX:** A bespoke design system using a palette of Cream, Gold, and Deep Red with elegant typography.
- **Interactive Menu:** Explore categories and dishes through a natural conversational interface.
- **Live Cart Management:** Instant updates, quantity adjustments, and real-time total calculation.
- **Mobile Ready:** Fully responsive design, prepared for Android deployment via Capacitor.
- **Micro-Animations:** Smooth transitions and hover effects for a premium feel.

## 🛠️ Technology Stack
- **Frontend:** React 19 + Vite
- **Styling:** Tailwind CSS (Custom luxury theme)
- **Icons:** Lucide React
- **Mobile Wrapper:** Capacitor (Android Support)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/harsh8907-k/luxury-cafe-concierge.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 📱 Android Deployment
To run on Android:
1. Build the project: `npm run build`
2. Sync with Capacitor: `npx cap sync`
3. Open in Android Studio: `npx cap open android`
